Готово

FL Studio: Options → Manage plugins → Find more plugins (или Start scan). Clipline появится в списке.

Logic Pro / GarageBand: просто откройте программу — Audio Units подхватываются автоматически (Audio FX → Audio Units → Clipline Audio → Clipline).

Ableton Live: Settings → Plug-Ins → Rescan.

Ваши пресеты хранятся в ~/Library/Application Support/Clipline/Presets.

Rescan plugins in your DAW. Logic Pro picks up the Audio Unit automatically.
