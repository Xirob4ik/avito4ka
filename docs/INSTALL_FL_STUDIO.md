# Установка в FL Studio

## 1. Установка плагина

1. Запустите `Clipline-0.1.0-Win64-Setup.exe`.
2. Windows покажет запрос контроля учётных записей (UAC): нажмите **Да**. Права нужны, чтобы записать файл в `C:\Program Files\Common Files\VST3`.
3. Если появится SmartScreen («Windows защитила ваш компьютер»): установщик не подписан цифровой подписью, поэтому нажмите **Подробнее → Выполнить в любом случае**.
4. Нажмите **Установить**. Перед этим закройте FL Studio: загруженный плагин нельзя заменить.

Результат: `C:\Program Files\Common Files\VST3\Clipline.vst3`.

## 2. Поиск плагина в FL Studio (20, 21, 2024, 2025)

1. **Options → Manage plugins** (или F10 → «Manage plugins»).
2. Слева в **Plugin search paths** должна быть строка `C:\Program Files\Common Files\VST3`. По умолчанию она там есть; если нет, добавьте её кнопкой с папкой.
3. Нажмите **Find more plugins**, при первой настройке **Start scan**. Включите опцию **Verify plugins**, тогда FL Studio один раз загрузит плагин для проверки.
4. Найдите в списке **Clipline** (производитель «Clipline Audio», тип VST3, категория Effect). Отметьте звёздочкой, чтобы он появился в быстрых меню.
5. Закройте окно менеджера.

## 3. Использование

* **Микшер:** выберите канал → свободный слот эффекта (▼) → **Select → Clipline**.
* **Пресеты:** верхняя панель плагина, стрелки ‹ › или клик по имени. Свои пресеты сохраняются через это же меню в `%APPDATA%\Clipline\Presets`.
* **Задержка:** при оверсэмплинге плагин сообщает FL Studio свою задержку (4× = 60 сэмплов). FL Studio компенсирует её автоматически (Plugin Delay Compensation включён по умолчанию). Сдвиг значения показан внизу справа, в строке OVERSAMPLING.
* **Автоматизация:** покрутите нужную ручку плагина, затем в FL Studio выберите **Tools → Last tweaked → Create automation clip** (или **Link to controller** для MIDI-контроллера). Все 8 параметров плагина автоматизируются; их также видно в меню окна плагина FL Studio (стрелка в левом верхнем углу → Browse parameters).
* **Сброс ручки:** двойной клик. **Точная подстройка:** Shift или Ctrl при перетаскивании. **Ввод числа:** клик по значению под ручкой.

## 4. Ableton Live и REAPER

* **Ableton Live 11/12:** Settings → Plug-Ins → включите «Use VST3 Plug-In System Folders» → **Rescan**. Плагин появится в браузере: Plug-Ins → VST3 → Clipline Audio.
* **REAPER:** Options → Preferences → Plug-ins → VST → убедитесь, что `C:\Program Files\Common Files\VST3` есть в списке путей → **Re-scan**.

## 5. Если что-то не так

| Симптом | Что сделать |
|---|---|
| Плагина нет в списке | Проверьте, что файл `C:\Program Files\Common Files\VST3\Clipline.vst3\Contents\x86_64-win\Clipline.vst3` существует; в Manage plugins нажмите Find more plugins ещё раз. Нужна 64-битная FL Studio. |
| Установщик пишет «Cannot replace … / Не удаётся заменить» | Плагин загружен: закройте FL Studio (и другие DAW) и запустите установщик снова. |
| Интерфейс рисуется с артефактами | Меню **⋯** (правый верхний угол плагина) → **Software rendering**. Настройка запоминается. |
| Нужно удалить | Параметры Windows → Приложения → **Clipline (VST3)** → Удалить. |
