# Известные ограничения

## Что не проверено

* **Загрузка в реальных DAW не проверена мной:** FL Studio, Ableton Live, REAPER, Logic Pro. На настоящих Windows и macOS (GitHub Actions) пройдены юнит-тесты, загрузка мини-хостом, установка, pluginval на максимальной строгости (VST3 и AU) и `auval` ([TESTING.md](TESTING.md)).
* **Отрисовка Direct2D на настоящей видеокарте не проверена.** Если интерфейс рисуется с артефактами, включите меню ⋯ → **Software rendering**: выбор запоминается.
* **Установщики не подписаны.** Windows SmartScreen может предупредить при первом запуске (Подробнее → Выполнить в любом случае). Mac `.pkg` не подписан Apple Developer ID и не нотаризован: при первом открытии нужен обход Gatekeeper ([INSTALL_MAC.md](INSTALL_MAC.md)). Для публичного распространения нужны сертификаты подписи.

## Сборка

* Основная сборка Windows — MSVC (Visual Studio) на GitHub Actions; установщик пользователя собран именно так. Запасной путь — кросс-сборка llvm-mingw на Linux: JUCE 8 официально не поддерживает MinGW, это обходит минимальный патч (`cmake/patches/juce-8.0.8-clipline.patch`) и compat-файлы.
* В кросс-сборке MinGW нет `moduleinfo.json`: его нельзя сгенерировать при кросс-компиляции, а для VST3 он необязателен. Сборки MSVC и macOS создают его автоматически.
* AAX, CLAP и Linux-плагин не собирались.

## Звук

* **CEILING вкл.** гарантирует потолок, но на жёстко срезанных высоких частотах возвращает часть алиасинга (измерения в [ALGORITHMS.md](ALGORITHMS.md)). **CEILING выкл.** даёт самый чистый оверсэмплинг, но пики после фильтров могут превышать CLIP: до ~1.6 дБ на тонах выше 10 кГц и до ~3–4 дБ на шумном материале.
* Нет DC-фильтра: клиппер сам постоянную составляющую не создаёт, но та, что уже есть во входном сигнале, проходит насквозь (как и в большинстве клипперов).
* Нет режима «true peak» с измерением межсэмпловых пиков; индикатор OVER смотрит на сэмплы, а не на восстановленный аналоговый сигнал.
* FOLD — экспериментальный режим: wavefolder даёт много высоких гармоник, поэтому для него особенно важен оверсэмплинг 4×–8×.
* Задержка 49–65 сэмплов при оверсэмплинге компенсируется хостом (PDC). При живой игре через плагин в реальном времени её может быть слышно; используйте 1× (без задержки).

## Интерфейс

* Пресеты не отображаются как «программы» хоста (меню пресетов DAW): управление ими только в самом плагине. Так сделано намеренно, чтобы в списке автоматизации не было лишнего параметра.
* Хост видит 9 параметров: 8 параметров плагина и стандартный Bypass, который JUCE добавляет в VST3.
* Правый клик по элементам плагина не открывает меню хоста (автоматизация через средства DAW, см. [INSTALL_FL_STUDIO.md](INSTALL_FL_STUDIO.md)).
* Интерфейс плагина на английском (как принято в аудио-ПО); установщик на русском/английском.

## Найдено и исправлено в процессе

* Ошибка JUCE 8.0.8: если `IDXGIOutput::WaitForVBlank` возвращает ошибку (дисплей отключён, удалённый рабочий стол, виртуальный дисплей), поток VBlank не видел запрос на завершение, и закрытие окна плагина зависало навсегда, а вместе с ним и DAW. Исправлено патчем (`cmake/patches/juce-8.0.8-clipline.patch`); патч применяется ко всем сборкам автоматически.
* Тесты на MSVC падали с переполнением стека: объект плагина большой (буфер осциллографа), а MSVC отводит каждой локальной переменной теста своё место на стеке. Для самого плагина это неважно, DAW создаёт его в куче; тесты теперь тоже создают его в куче.
* Первая кросс-сборка (MinGW) не загружалась в реальной Windows: «Точка входа в процедуру TaskDialogIndirect не найдена». Компоновщик MinGW игнорирует прагму JUCE, которая встраивает в DLL манифест comctl32 v6, и Windows подставляла старую comctl32 5.82. Исправлено: манифест встраивается явно (`cmake/mingw-compat/comctl32-v6.*`). Wine этого различия не воспроизводит, поэтому ошибку нашёл пользователь на реальной Windows.
