# Функции Clipline 0.1.0

## Обработка

* **4 режима клиппинга** с разной математикой ([ALGORITHMS.md](ALGORITHMS.md)): HARD (жёсткий срез), SOFT (tanh), CUBIC (кубическое насыщение с плавным выходом на порог), FOLD (треугольный wavefolder).
* **CLIP** (порог) от −24 до 0 dBFS, по умолчанию −3.
* **INPUT** и **OUTPUT** ±24 дБ, шаг 0.1 дБ.
* **MIX** 0–100 %: сухой сигнал задержан ровно на задержку оверсэмплинга, поэтому параллельный клиппинг не даёт гребенчатой фильтрации.
* **Оверсэмплинг** 1× / 2× / 4× / 8×: FIR-фильтры с линейной фазой, целочисленная задержка 0 / 49 / 60 / 65 сэмплов, сообщается хосту для компенсации, переключение на ходу без щелчков.
* **CEILING** (вкл. по умолчанию): CLIP остаётся настоящим потолком и после фильтров оверсэмплинга.
* **LINK**: общий коэффициент для обоих каналов, стереокартина сохраняется. Без LINK каналы обрабатываются независимо.
* Моно и стерео (моно ↔ моно, стерео ↔ стерео).
* Сглаживание всех непрерывных параметров (20 мс), кроссфейды 5 мс при смене режима, LINK и оверсэмплинга.
* Bypass хоста без щелчков и без сдвига по времени.
* Защита от NaN/Inf, денормализованных чисел и экстремальных уровней; клиппер не создаёт постоянной составляющей.
* Работа в реальном времени: без выделений памяти и блокировок в аудиопотоке, результат не зависит от размера блока хоста.

## Параметры (автоматизация)

8 параметров со стабильными ID. ID записываются в проекты DAW и в автоматизацию, поэтому они никогда не меняются:

| ID | Имя в хосте | Диапазон | По умолчанию |
|---|---|---|---|
| `input` | Input Gain | −24…+24 дБ | 0 |
| `clip` | Clip Threshold | −24…0 dBFS | −3 |
| `output` | Output Gain | −24…+24 дБ | 0 |
| `mix` | Dry/Wet Mix | 0…100 % | 100 |
| `mode` | Clipping Mode | Hard / Soft / Cubic / Wavefold | Hard |
| `os` | Oversampling | 1x / 2x / 4x / 8x | 4x |
| `link` | Stereo Link | On / Off | On |
| `ceiling` | True Ceiling | On / Off | On |

Состояние (все параметры и имя пресета) сохраняется в проекте DAW. Повреждённое или чужое состояние игнорируется, значения вне диапазона ограничиваются.

## Пресеты

Заводские: Init, Clean Peak Control, Mix Bus Clipper, Punchy Drums, Aggressive Drums, 808 Control, Soft Saturation, Cubic Warmth, Hyperpop Smash, Wavefold Texture.
Пользовательские сохраняются в `%APPDATA%\Clipline\Presets\*.clpreset` (XML). Если после выбора пресета что-то изменить, к имени добавляется отметка «изменён». Переключение стрелками, переход по кругу.

## Интерфейс

* Тёмная тема (#101010, поверхности #181818/#202020, текст #F2F2F2/#888888, акцент #C5F467, предупреждения красно-оранжевым), шрифты Geist / Geist Mono (моноширинные цифры).
* Окно 900×560, масштабируется от 675×420 до 1440×896 с сохранением пропорций (угол справа внизу); размер запоминается.
* **Верхняя панель:** логотип, пресеты (‹ имя ›, меню, сохранение), мини-индикаторы IN/OUT с пиками, меню ⋯ (окно осциллографа, подсказки, сброс пиков, папка пресетов, программная отрисовка в Windows, About).
* **Осциллограф:** вход/выход/срезанная часть, линии порога с подписью в дБ (перетаскиваются мышью, Shift/Ctrl (на Mac Shift/Cmd) для точности, двойной клик сбрасывает), окно 5–80 мс колесом мыши.
* **Ручки** CLIP (главная, крупнее, с акцентом), INPUT, MIX, OUTPUT:
  * перетаскивание вверх/вниз, Shift/Ctrl (на Mac Shift/Cmd) в 10 раз точнее;
  * колесо мыши;
  * двойной клик сбрасывает к значению по умолчанию;
  * клик по значению открывает ввод числа: понимает «-7.5 dB», «-7,5», «35%», «-inf»; текст без числа игнорируется.
* **MODE, OVERSAMPLING:** сегментные переключатели с подсказками. Текущая задержка показана в мс и сэмплах.
* **LINK, CEILING:** переключатели-чипы.
* **Мониторинг:** вертикальные измерители IN/OUT со шкалой, удержанием пика и численными максимумами; индикатор CLIP (сколько дБ срезается); OVER (защёлка при превышении 0 dBFS).
* Подсказки на всех элементах (можно отключить).

## Установка

* Установщик `Clipline-0.1.0-Win64-Setup.exe`: один файл без зависимостей, русский/английский интерфейс по языку Windows, запись в «Приложения», тихий режим `/S`, деинсталлятор, пресеты пользователя при удалении сохраняются.
